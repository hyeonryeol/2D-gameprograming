1. 게임과 2D 게임의 정의

게임은 가상 월드에 존재하는 여러 객체들의 상호작용을 시뮬레이션하고, 그 결과를 렌더링하는 프로그램이다

  • 2D 게임: 현재 진행 중인 게임 가상 월드의 내용을 화면에 2D 그림으로 보여주는 것.
  • 배경 / 월드: 캐릭터와 오브젝트가 존재하고 움직이는 게임 속 공간을 만듦.
  • 캐릭터 / 오브젝트: 좌표와 상태를 가지며, 이동하거나 충돌하고 서로 영향을 주는 대상임.
  • UI / 입력 / AI / 사운드: 플레이어에게 정보를 주고, 조작을 받아들이며, 게임의 반응과 분위기를 만듦.

2. 좌표계 ★★

pico2d 캔버스는 왼쪽 아래가 원점 (0, 0). 오른쪽이 x+, 위쪽이 y+

(0, 599) ┌──────────────┐ (799, 599)
         │   800 × 600  │
         │      ↑ y     │
  (0, 0) └──── → x ─────┘ (799, 0)
  • draw(x, y)의 (x, y)는 이미지 가운데 위치. 잔디 draw(400, 30)는 가로 가운데, 바닥 쪽.
  • 마우스 이벤트는 반대로 왼쪽 위가 원점이고 아래로 y가 증가. 그래서 변환이 필요.
canvas_y = canvas_height - 1 - event.y   # x는 그대로, y만 뒤집기
# 600 높이에서 마우스 y = 0 (맨 위)   → 599
#              마우스 y = 599 (맨 아래) → 0

- 1을 하는 이유: 픽셀 번호가 0부터라 0~599까지만 있기 때문.

3. 게임 로직과 렌더링, 게임 루프

  • 게임 로직: 캐릭터의 위치, 방향, 점수처럼 게임 객체의 상태를 계산하는 단계.
  • 게임 렌더링: 계산된 현재 상태를 배경과 캐릭터 이미지로 그리고 화면에 반영하는 단계.
  • 이 두 단계와 화면 갱신이 계속 반복되기 때문에 게임 안에서 시간이 흐르고 객체가 살아 움직이는 것처럼 보임.
open_canvas()
reset_world()          # 객체 만들기
while running:
    handle_events()    # 입력
    update_world()     # 로직  상태 계산
    render_world()     # 렌더링  clear_canvas → draw → update_canvas
    delay(0.05)
close_canvas()

4. 클래스 코드 그대로 쓰기 ★

class Grass:
    def __init__(self):
        self.image = load_image('grass.png')
    def draw(self):
        self.image.draw(400, 30)
    def update(self): pass
  • __init__: 밑줄 두 개씩 양쪽. 생성자, 객체가 생성될 때 맨 처음 자동 호출. 초기 상태(속성, 멤버 변수)를 설정.
  • self: 생성된 객체를 가리키는 변수. 멤버 함수는 항상 첫 번째 인자가 self.
  • update는 잔디가 할 일이 없어 pass. 그래도 만들어 두면 world 리스트에서 모든 객체에 o.update()를 똑같이 부를 수 있음.
  • 생성: grass = Grass(). 들여쓰기 틀리면 IndentationError.

5. 추상화와 게임 객체

추상화(Abstraction): 꼭 필요로 하는 객체들만, 꼭 보여줘야 할 내용만, 꼭 보여줘야 할 움직임만

  • 게임 객체(Game Object): 게임 월드를 구성하는 모든 요소들을 지칭.
  • 게임 객체의 본질: 속성과 행동의 모음.
    • 속성: 게임 객체의 현재 상태, 상태를 나타내는 값 (x, y, frame)
    • 행동: 시간에 따라, 혹은 이벤트에 반응해서 상태가 변하는 방식 (x = x + 2)
  • 클래스: 유사한 객체들에 공통으로 필요한 데이터와 함수를 정의하는 소프트웨어 단위. 객체를 찍어내는 "도장".
  • 클래스로 객체를 찍어내는 과정 = Object Instantiation.

1. 계산과 출력

/는 항상 실수, //는 내림한 몫, %는 나머지, **는 거듭제곱

print(1 / 2)     # 0.5
print(1 // 2)    # 0
print(4 / 3)     # 1.3333333333333333
print(4 // 3)    # 1
print(7 % 3)     # 1     7 = 3 × 2 + 1
print(7.5 % 3)   # 1.5   실수에도 % 가능
print(2 ** 3)    # 8
print(1024 / 8)  # 128.0  나누어떨어져도 실수
  • 정수는 크기 제한이 없다. 2**1024도 그대로 출력.
  • 우선순위: ** → * / // % → + -. 괄호로 바꿈. pi * r ** 2는 r을 먼저 제곱.
  • 125초를 분과 초로: 125 // 60 → 2, 125 % 60 → 5.
  • 게임에서: frame = (frame + 1) % 8은 0~7 순환, image.w // 10은 프레임 한 칸 너비(정수).

9. while과 if

블록은 들여쓰기로 정한다. 같은 깊이 = 같은 블록

import turtle
count = 12
while count > 0:          # 참인 동안 반복
    turtle.forward(100)
    turtle.left(30)
    count -= 1            # 빠뜨리면 무한 반복
else:
    print('count is zero')  # break 없이 끝났을 때만

12번 돌고 30° × 12 = 360°라 정12각형. count = 3이면 3, 2, 1일 때 실행하고 0에서 멈춰 3회.

while True:
    shape = input('Enter Shape: ')
    if shape == 'circle':
        turtle.circle(50)
    elif shape == 'triangle':
        turtle.forward(50); turtle.left(120)
        turtle.forward(50); turtle.left(120)
        turtle.forward(50)
    elif shape == 'quit':
        break              # 가장 가까운 반복문 탈출
    else:
        print('Wrong Shape')
  • if / elif / else 연결은 위에서부터 검사해 처음 참인 블록 하나만 실행.
  • star 입력 → Wrong Shape. quit → break로 while True 종료.
  • 본문을 비워 둘 수 없으니 자리만 잡을 땐 pass (LEC06 while True: pass).

LEC 052D 게임 기초: 2D 렌더링

게임과 2D 게임의 정의

게임은 가상 월드에 존재하는 여러 객체들의 상호작용을 시뮬레이션하고, 그 결과를 렌더링하는 프로그램이다.

가상 월드→게임 객체→상호작용 계산→화면에 보여주기
  • 2D 게임: 월드의 위치와 움직임을 평면 좌표 x, y로 표현하고, 배경, 캐릭터, 오브젝트 이미지를 조합해 한 장면을 만든다. 3D와의 차이는 주로 "어떻게 화면에 보여주는가".
  • 렌더링: 계산된 게임 상태를 화면에 보여주는 과정. 플레이어는 변수를 못 보니 이미지, 위치, 애니메이션, UI로 바꿔 보여준다.
  • 구성 요소: 배경과 월드, 캐릭터와 오브젝트(좌표와 상태를 가짐), UI, 입력, AI, 사운드.

세 가지 운동의 좌표

def draw_boy(x, y):                      # 공통 그리기 함수로 분리

    boy.draw(x, y)
    update_canvas()

def move_circle():                       # 원: 중심 + 반지름 × cos, sin
    for degree in range(360):
        theta = math.radians(degree)
        x = 400 + 200 * math.cos(theta)
        y = 300 + 200 * math.sin(theta)
        draw_boy(x, y)

def move_top():                          # 사각: 한 변은 한 좌표만 변함
    for x in range(50, 751, 5):
        draw_boy(x, 550)
  • 원운동: x = 중심 x + 반지름 × cos θ, y = 중심 y + 반지름 × sin θ. 각도는 math.radians로 라디안 변환.
  • 사각 운동: move_top, right, bottom, left 네 함수로 나눈다. 상단 x 증가, 오른쪽 y 감소, 하단 x 감소, 왼쪽 y 증가.
  • 삼각 운동: 대각선은 두 점 사이 보간. x = x0 + (x1 − x0) × t, y = y0 + (y1 − y0) × t (t는 0 → 1).
  • 리팩터링: 이동 함수는 좌표 계산, draw_boy는 화면 출력. 바꾼 뒤 결과가 전과 같은지 확인.

close_canvas()는 while True를 빠져나오기 전에는 실행되지 않는다.

이벤트와 처리 단계

이벤트발생 시점
SDL_KEYDOWN키를 누른 순간
SDL_KEYUP키를 뗀 순간
SDL_MOUSEMOTION마우스가 움직인 순간
SDL_QUIT창 닫기 버튼을 누른 순간
이벤트 수집 get_events()→종류 확인 event.type→세부 정보 event.key, event.x, event.y

키를 누르고 있는 동안 KEYDOWN이 계속 생기지 않는다. 마우스도 가만히 있으면 이벤트가 없다.

def handle_events():
    global running                    # 없으면 지역 변수가 돼서 ESC를 눌러도 안 꺼짐
    for event in get_events():        # 리스트라서 모두 순회해야 함
        if event.type == SDL_QUIT:
            running = False
        elif event.type == SDL_KEYDOWN and event.key == SDLK_ESCAPE:
            running = False

while running:
    handle_events()                   # 입력 → 상태 기록
    update()                          # 위치, 애니메이션 계산
    draw()                            # 화면 출력

연속 이동: dir 상태

이벤트는 상태(dir)만 바꾸고, 실제 이동은 update에서 매 프레임 x += dir × speed.

if event.type == SDL_KEYDOWN:
    if event.key == SDLK_RIGHT: dir += 1
    elif event.key == SDLK_LEFT: dir -= 1
elif event.type == SDL_KEYUP:
    if event.key == SDLK_RIGHT: dir -= 1    # 눌렀을 때 한 것을 되돌림
    elif event.key == SDLK_LEFT: dir += 1

# update
x += dir * speed
if dir > 0: action = RUN_RIGHT
elif dir < 0: action = RUN_LEFT
else: action = IDLE
  • dir: −1 왼쪽, 0 정지, +1 오른쪽. 두 키를 같이 누르면 +1 − 1 = 0으로 정지, 그 상태에서 오른쪽만 떼면 −1.
  • KEYDOWN에서 바로 x += 10하면 한 번 누를 때 한 번만 움직인다.

마우스 좌표 변환

if event.type == SDL_MOUSEMOTION:
    x = event.x
    y = canvas_height - 1 - event.y   # Windows는 왼쪽 위 원점, pico2d는 왼쪽 아래
hide_cursor()                         # 시스템 커서 숨기기

x는 그대로, y만 뒤집는다. 픽셀이 0부터라서 엄밀하게는 height − 1 − y. 예: 600 높이에서 event.y = 0(맨 위) → 599.

LEC 11게임 오브젝트

객체, 속성, 행위, 클래스

게임 객체는 게임 월드를 구성하는 모든 요소이고, 본질은 속성(현재 상태)과 행동(상태가 변하는 방식)의 모음이다.

  • 추상화: 실제 세계에서 꼭 필요한 객체, 꼭 보여줄 내용, 꼭 보여줄 움직임만 고른다.
  • 속성: 객체의 상태를 나타내는 값(예: x). 행위: 상태를 바꾸는 것(예: x = x + 2). 속성 + 행위 = 소년 객체.
  • 클래스: 비슷한 객체들의 공통 데이터와 함수를 정의한 틀, 객체를 찍어내는 "도장".
  • 인스턴스: 클래스로 찍어 낸 각각의 객체. 찍어내는 과정이 instantiation.
  • __init__: 생성자, 객체가 만들어질 때 처음 자동 호출되어 초기 상태(멤버 변수)를 정한다. self는 그 객체 자신, 멤버 함수의 첫 인자는 항상 self.

class Grass:
    def __init__(self):
        self.image = load_image('grass.png')
    def draw(self):
        self.image.draw(400, 30)
    def update(self): pass

class Boy:
    def __init__(self):
        self.x, self.y = random.randint(100, 700), 90   # 시작 위치를 다르게
        self.frame = random.randint(0, 7)               # 애니메이션이 맞물리지 않게
        self.image = load_image('run_animation.png')
    def update(self):
        self.frame = (self.frame + 1) % 8
        self.x += 5
    def draw(self):
        self.image.clip_draw(self.frame * 100, 0, 100, 100, self.x, self.y)

world 리스트로 정리

def reset_world():
    global running, world
    running = True
    world = []
    world.append(Grass())
    team = [Boy() for i in range(11)]    # 리스트 컴프리헨션
    world += team

def update_world():
    for o in world:
        o.update()

def render_world():
    clear_canvas()
    for o in world:
        o.draw()
    update_canvas()

open_canvas()
reset_world()
while running:
    handle_events()
    update_world()
    render_world()
    delay(0.05)
close_canvas()
  • 모든 객체가 update(), draw()를 가지면 종류와 상관없이 world 하나로 돌릴 수 있다.
  • 소년 11명을 boy1 … boy11로 만들지 않고 [Boy() for i in range(11)].
  • Zombie처럼 시트 크기에서 프레임 크기를 계산할 수도 있다: frame_width = self.image.w // 10, 그리고 화면엔 절반 크기로 그림.

"왜 한 명만 보이지?" → 모두 같은 위치, 같은 frame에서 시작해서 겹친 것. random으로 위치와 frame을 다르게 준다.
