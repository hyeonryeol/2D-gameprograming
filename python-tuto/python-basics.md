# 1부 · 학습

## 1. 값과 변수

> 파이썬에서 `=` 는 "같다"가 아니라 "이 값에 이 이름을 붙인다"는 뜻입니다.
> 변수는 값을 담는 상자가 아니라, 값에 붙이는 이름표에 가깝습니다.

이름을 붙여 두면 그 뒤로는 값 대신 이름으로 부를 수 있습니다.
같은 이름에 다시 대입하면, 이름이 가리키는 값이 새 값으로 바뀝니다.

```python
score = 90            # 정수에 score 라는 이름을 붙인다
name = "hyeonryeol"   # 문자열
ratio = 0.85          # 실수
passed = True         # 불리언

print(name, score)
print(type(score))

score = score + 5     # 이름이 새 값을 가리키게 바꾼다
print(score)
```

출력:

```
hyeonryeol 90
<class 'int'>
95
```

### 자주 걸리는 곳 — 변수 이름은 숫자로 시작할 수 없습니다

```python
2nd = 10
```

```
SyntaxError: invalid syntax
```

이름에는 영문자, 숫자, 밑줄만 쓸 수 있고 첫 글자는 숫자가 될 수 없습니다.
`if`, `for`, `class` 같은 예약어도 이름으로 쓸 수 없습니다.

### 정리

- `=` 는 대입, `==` 가 비교입니다.
- 이름을 다시 대입하면 이전 값은 그냥 버려집니다.
- `type(값)` 으로 자료형을 확인할 수 있습니다.

## 2. 자료형과 형변환

> 파이썬은 값마다 자료형이 정해져 있고, 서로 다른 자료형을 함부로 섞으면
> 계산하지 않고 바로 에러를 냅니다. 섞고 싶으면 직접 바꿔야 합니다.

기본 자료형은 정수(`int`), 실수(`float`), 문자열(`str`), 불리언(`bool`) 네 가지입니다.
`int()`, `float()`, `str()`, `bool()` 로 서로 변환합니다.

```python
age = 21
print("age: " + str(age))   # 숫자를 문자열로 바꿔서 이어붙인다
print(int("42") + 8)        # 문자열을 정수로
print(float("3.14") * 2)

print(int(3.9))             # 반올림이 아니라 버림
print(bool(0), bool(""), bool([]))
```

출력:

```
age: 21
50
6.28
3
False False False
```

### 자주 걸리는 곳 — 문자열과 숫자는 `+` 로 이어지지 않습니다

```python
print("age: " + 21)
```

```
TypeError: can only concatenate str (not "int") to str
```

입문자가 가장 자주 만나는 에러입니다.
숫자를 `str()` 로 감싸거나 f-string 을 쓰면 해결됩니다.

### 정리

- `int()` 는 소수점을 버립니다. `int(3.9)` 는 3입니다.
- `0`, `""`, `[]` 는 모두 거짓으로 취급됩니다.
- 에러 메시지의 자료형 이름을 읽으면 원인이 바로 보입니다.

## 3. 연산자

> 산술 연산자 중 파이썬만의 함정은 나눗셈입니다.
> `/` 는 나누어떨어져도 항상 실수를 돌려주고, 몫이 필요하면 `//` 를 씁니다.

비교 연산의 결과는 언제나 `True` 또는 `False` 이고,
이 값들을 `and`, `or`, `not` 으로 엮어 조건을 만듭니다.

```python
a, b = 17, 5

print(a + b, a - b, a * b)
print(a / b)      # 나눗셈은 항상 실수
print(a // b)     # 몫
print(a % b)      # 나머지
print(a ** 2)     # 거듭제곱

print(a > b and b > 0)
print(not (a == 17))
```

출력:

```
22 12 85
3.4
3
2
289
True
False
```

### 자주 걸리는 곳 — 나누어떨어져도 `/` 의 결과는 실수입니다

```python
print(10 / 2)
print(10 // 2)
```

```
5.0
5
```

위 두 줄은 에러가 아니라 서로 다른 출력입니다.
개수나 인덱스처럼 정수가 필요한 자리에는 `//` 를 쓰세요.

### 정리

- `/` 는 실수, `//` 는 몫, `%` 는 나머지입니다.
- `%` 는 짝수 판별(`n % 2 == 0`)에 자주 쓰입니다.
- `and` 는 `or` 보다 먼저 계산됩니다. 헷갈리면 괄호를 쓰세요.

---

## 4. 문자열 다루기

> 문자열은 글자가 순서대로 늘어선 값입니다. 인덱스는 0부터 시작하고,
> 음수는 뒤에서부터 셉니다. 그리고 한번 만들어진 문자열은 고칠 수 없습니다.

슬라이스 `s[시작:끝]` 은 시작은 포함하고 끝은 포함하지 않습니다.
이 규칙이 `range()` 에도 그대로 적용되므로 지금 익혀 두면 좋습니다.

```python
s = "python"

print(s[0], s[-1])       # 첫 글자, 마지막 글자
print(s[1:4])            # 1 이상 4 미만
print(len(s))
print(s.upper())

print("a,b,c".split(","))
print("  hi  ".strip())
print(f"{s} has {len(s)} letters")
```

출력:

```
p n
yth
6
PYTHON
['a', 'b', 'c']
hi
python has 6 letters
```

### 자주 걸리는 곳 — 문자열은 일부만 바꿔 쓸 수 없습니다

```python
s = "python"
s[0] = "P"
```

```
TypeError: 'str' object does not support item assignment
```

고치고 싶다면 새 문자열을 만들어야 합니다. `s = "P" + s[1:]` 처럼 씁니다.

### 정리

- 인덱스는 0부터, `s[-1]` 은 마지막 글자입니다.
- 슬라이스의 끝 번호는 포함되지 않습니다.
- `f"{변수}"` 형태의 f-string 이 가장 편한 출력 방법입니다.

## 5. 리스트와 딕셔너리

> 리스트는 순서로 꺼내는 묶음이고, 딕셔너리는 이름표로 꺼내는 묶음입니다.
> 게임 코드에서는 적 목록은 리스트로, 캐릭터 상태는 딕셔너리로 두는 식으로 씁니다.

리스트는 `append()` 로 뒤에 붙이고 인덱스나 슬라이스로 꺼냅니다.
딕셔너리는 `d[키]` 로 읽고 쓰며, 없는 키에 대입하면 새로 만들어집니다.

```python
scores = [90, 75, 88]
scores.append(100)
print(scores, len(scores))
print(scores[1:3])
print(max(scores), sum(scores))

user = {"name": "hyeonryeol", "level": 3}
user["level"] = 4        # 있는 키면 수정
user["hp"] = 120         # 없는 키면 추가
print(user["name"], user["level"])
print("hp" in user)
```

출력:

```
[90, 75, 88, 100] 4
[75, 88]
100 353
hyeonryeol 4
True
```

### 자주 걸리는 곳 — 없는 자리를 읽으면 에러입니다

```python
scores = [90, 75, 88]
print(scores[3])
```

```
IndexError: list index out of range
```

딕셔너리에서 없는 키를 읽으면 `KeyError` 가 납니다.
읽기 전에 `in` 으로 확인하는 습관이 안전합니다.

### 정리

- 리스트 길이가 4면 쓸 수 있는 인덱스는 0~3입니다.
- `in` 은 리스트와 딕셔너리 모두에서 쓸 수 있습니다.
- 딕셔너리의 `in` 은 값이 아니라 키를 찾습니다.

## 6. 조건문

> 파이썬은 중괄호 대신 들여쓰기로 블록을 구분합니다.
> 들여쓰기가 문법이라는 점이 다른 언어와 가장 크게 다른 부분입니다.

조건 줄은 콜론으로 끝나고, 그 아래 줄들은 공백 4칸 들여씁니다.
`elif` 는 위에서부터 검사해 처음 참이 된 하나만 실행하고 나머지는 건너뜁니다.

```python
score = 82

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"

print(grade)
```

출력:

```
B
```

### 자주 걸리는 곳 — 콜론 다음 줄은 반드시 들여씁니다

```python
if score >= 90:
print("A")
```

```
IndentationError: expected an indented block after 'if' statement on line 1
```

탭과 공백을 섞어 써도 `TabError` 가 납니다.
편집기에서 탭을 공백 4칸으로 설정해 두세요.

### 정리

- 조건 줄 끝의 콜론과 4칸 들여쓰기가 한 세트입니다.
- `elif` 는 여러 개 참이어도 처음 하나만 실행됩니다.
- 위 예제에서 `score = 95` 라면 A 하나만 출력됩니다.

## 7. 반복문

> `for` 는 정해진 것들을 하나씩 훑을 때, `while` 은 조건이 참인 동안 계속할 때 씁니다.
> 게임 루프가 바로 `while` 문입니다.

`range(n)` 은 0부터 n-1까지를 만듭니다. n은 포함되지 않는다는 점이 슬라이스와 같습니다.
`break` 는 반복을 완전히 끝내고, `continue` 는 이번 회차만 건너뜁니다.

```python
for i in range(3):
    print(i, end=" ")
print()

for name in ["kim", "lee", "park"]:
    print(name.upper(), end=" ")
print()

n = 1
while n < 20:
    n = n * 3
print(n)

for i in range(10):
    if i == 3:
        continue      # 3만 건너뛴다
    if i > 5:
        break         # 6에서 완전히 멈춘다
    print(i, end=" ")
```

출력:

```
0 1 2 
KIM LEE PARK 
27
0 1 2 4 5 
```

### 자주 걸리는 곳 — `range(3)` 에 3은 들어 있지 않습니다

```python
for i in range(1, 4):
    print(i, end=" ")
```

```
1 2 3
```

`range(시작, 끝)` 도 끝은 포함하지 않습니다.
1부터 3까지 필요하면 `range(1, 4)` 라고 씁니다.

### 정리

- `range(5)` 는 0, 1, 2, 3, 4 입니다.
- `while` 은 조건을 거짓으로 만드는 줄이 안에 없으면 무한 반복합니다.
- `break` 는 반복 종료, `continue` 는 이번 회차만 건너뜀입니다.

## 8. 함수

> 같은 일을 여러 번 한다면 이름을 붙여 묶습니다. `def` 로 정의하고,
> `return` 으로 결과를 돌려줍니다. `return` 이 없으면 `None` 이 돌아옵니다.

매개변수에 기본값을 주면 호출할 때 생략할 수 있습니다.
함수 안에서 만든 변수는 함수 밖에서는 존재하지 않습니다.

```python
def add(a, b):
    return a + b

def greet(name, mark="!"):
    return "hi " + name + mark

print(add(2, 3))
print(greet("lee"))
print(greet("kim", "?"))

def show(x):
    print(x)          # return 이 없다

result = show(5)
print(result)
```

출력:

```
5
hi lee!
hi kim?
5
None
```

### 자주 걸리는 곳 — 함수 안의 변수는 밖에서 쓸 수 없습니다

```python
def calc():
    total = 10

calc()
print(total)
```

```
NameError: name 'total' is not defined
```

값을 밖으로 꺼내려면 `return` 으로 돌려주고, 호출한 쪽에서 변수에 받아야 합니다.

### 정리

- `print()` 는 화면에 보여줄 뿐, 값을 돌려주지 않습니다.
- `return` 이 없는 함수의 반환값은 `None` 입니다.
- 기본값이 있는 매개변수는 뒤쪽에 몰아서 씁니다.

# 3부 · 평가 15문항

객관식입니다. 모두 고른 뒤 [부록](#평가-정답)에서 채점하세요.

**01.** 변수에 값을 넣을 때 쓰는 기호는 무엇일까요?
