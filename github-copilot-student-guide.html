01 / READY

신청 전에 준비할 것

ACCOUNT

본인의 GitHub 계정

개인 계정이 필요합니다. 학위·학력 인정 교육과정에 재학 중인 만 13세 이상 학생이 신청할 수 있습니다.

SCHOOL EMAIL

학교 이메일 확인

신청 화면에서 요구하면 GitHub 계정에 학교 이메일을 추가하고 인증하세요. 학교별로 요구 조건이 다릅니다.

ENROLLMENT

현재 재학 증빙

현재 재학 날짜가 있는 학생증, 수강 시간표, 성적표 또는 재학증명서 등을 준비하고 신청 화면의 요구를 따르세요.

신청 자격·인정 서류: GitHub Education 공식 문서 [1]

02 / APPLY

무료 이용까지 4단계

학생 인증 신청 → 심사 승인 → Copilot 활성화 → 에디터 로그인

1

학생 인증 신청하기

Education benefits 설정 ↗에 로그인한 뒤 GitHub Education의 Start an application을 선택하세요.

학생 신청 양식과 요청된 증빙을 작성하고 Submit application을 누릅니다. [1]

2

승인 결과 확인하기

신청 상태를 확인하고 보완 요청이 있으면 반영하세요. 승인 후에도 Copilot 혜택 적용에는 며칠이 더 걸릴 수 있습니다. [2]

3

Copilot Student 활성화하기

같은 Education benefits 페이지 ↗에서 Free GitHub developer resources for students and teachers 아래 Learn more를 선택하세요.

안내에 따라 Copilot Student를 활성화하고 이용 정책을 설정합니다. 학생 인증 승인과 Copilot 활성화는 별도 단계입니다. [2]

4

VS Code에서 같은 계정으로 로그인하기

VS Code 상태 표시줄의 Copilot 아이콘에서 Use AI Features를 선택하고 학생 인증에 사용한 GitHub 계정으로 로그인하세요. 기존 Copilot 구독이 적용됩니다.

다른 계정이라면 Accounts 메뉴에서 로그아웃 후 다시 로그인합니다. Copilot Chat을 열어 아래처럼 질문해 보세요. [4]

파이썬 리스트와 튜플의 차이를 짧은 예제로 설명해줘.

03 / CHECK

막히는 지점, 여기서 확인하세요

승인됐는데 Free 또는 결제 화면이 나와요.

Copilot 설정 또는 무료 활성화 페이지에서 다시 시도하세요. 유료 옵션만 보이면 구매하지 말고 며칠 후 확인합니다. 계속되면 GitHub Support에 문의하세요. [2]

학교 이메일이 없거나 인식되지 않아요.

학교가 이메일을 발급하지 않으면 해당 정책을 설명하는 학교 웹페이지나 공식 서신을 제출해 재신청하세요. 도메인이 인식되지 않으면 학교명·학교 URL·이메일 도메인을 GitHub Education Support에 전달하세요. [1]

한 번 승인받으면 계속 무료인가요?

GitHub는 매월 자격을 재평가합니다. 계속 이용하려면 학생 자격을 유지하고 계정에 표시되는 재인증 안내를 확인하세요. [2]

인증 전에도 무료로 써볼 수 있나요?

일반 Copilot Free는 제한된 기능과 사용량을 무료로 제공합니다. Copilot Student에는 별도의 학생 인증이 필요하며, 두 무료 플랜 모두 AI 크레딧 제공량이 정해져 있습니다. 최신 한도는 공식 플랜 안내와 계정 화면을 확인하세요. [3]

완료 체크리스트

직접 체크하는 메모입니다. 새로 열면 체크 상태가 저장되지 않을 수 있습니다.

첫 과제에 활용하는 방법

“정답 코드”만 요청하기보다 개념 설명, 오류 원인, 테스트 예제를 물어보세요. 제안된 코드는 직접 실행하고 이해하며, 과목의 AI 사용 지침을 따르세요.
